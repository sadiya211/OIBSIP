## 📌 Objective
Train ML classifiers to identify iris flower species 
(Setosa, Versicolor, Virginica) from physical measurements.

---

## 📊 Dataset
- Source: Built-in sklearn (load_iris())
- 150 samples | 4 features | 3 classes
- No missing values

---

## 🤖 Models Used
| Model | Accuracy |
|---|---|
| Logistic Regression | 100% |
| K-Nearest Neighbors | 100% |
| Decision Tree | 100% |
| Random Forest | 100% |

---

## 📈 Key Findings
- Setosa is perfectly separable from other species
- Petal length and petal width are most discriminative features
- All models achieved 100% — expected for this clean benchmark dataset
- Random Forest selected as best model for robustness
